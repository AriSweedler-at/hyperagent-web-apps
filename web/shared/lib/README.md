# web/shared/lib

Pure, leaf-level TypeScript both games import (docs/ARCHITECTURE.md "Module boundaries and
contracts"). Compiled by `tsconfig.pure.json` without DOM or node libs; lint runs the full
functional profile here (no loops, `let`, mutation, classes, `throw` or expression statements).

| Module              | Holds                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `result.ts`         | `Result<T, E>` and `ok / err / map / mapErr / andThen / unwrapOr`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `rng.ts`            | `Rng = () => number`; `mulberry32` re-exported from `rng.algorithms.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `shuffle.ts`        | `shuffle<T>(items, rng)`: gin's top-down Fisher-Yates (m − 1 rng calls for m items), generic over the item so every card game deals the same permutation from the same seeded stream; gin's `cards.ts` re-exports it at its legacy signature                                                                                                                                                                                                                                                                                                                                                                     |
| `json.ts`           | Decoder combinators over `unknown` returning `Result<T, DecodeError>`: leaves, `arrayOf`, `pair`, `record`, `object` (optional fields become optional keys), `oneOf`, `taggedUnion` (one case decoder per tag, run over the whole input and returned unchanged), `map`, `refine`                                                                                                                                                                                                                                                                                                                                 |
| `game.ts`           | The two-seat primitives both engines re-export from their `engine/types.ts` (`Seat`, `Pair<T>`, `Player`, `Now`, `RuleError`), the helpers `SEATS` / `otherSeat` / `setAt`, the decoders `seat` / `count` / `timestamp`, and `TwoSeatEngine<S, V, A, Opts>`: the contract each engine's `index.ts` publishes as `ENGINE` (`create`, `apply`, `viewFor`, `legalActions`, `actorOf`, `over`, `decodeState`, `decodeView`, `decodeAction`), which the shared shell's `cfg.engine`, the replay harness and the codecs type against                                                                                   |
| `roomCode.ts`       | Room-code alphabets, lengths, peer-id prefixes, sanitiser/validator per game                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `protocol.ts`       | The two-seat wire protocol (shared-shell design §4.5): `twoSeatProtocol({ decodeAction, decodeView, room })` gives a game its seven frame builders and three decoders with the legacy key order (`welcome`/`lobby` spread the room after `hostName`), plus `isGuestFrame`, `guestNameFor` and the `WIRE_TAGS`/`NAME_MAX`/`TOAST_MAX`/`DEFAULT_GUEST_NAME` literals                                                                                                                                                                                                                                               |
| `clock.ts`          | `Clock` and `Timer` types; implementations live in `web/shared/edge/clock*`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `invite.ts`         | The `?join=<code>` invite link every game shares: `JOIN_PARAM`, `inviteUrl`; the readers (`joinCodeFrom`, `withoutJoin`) live in `web/shared/edge/invite.ts`, over the platform's `URLSearchParams`                                                                                                                                                                                                                                                                                                                                                                                                              |
| `name.ts`           | `normaliseName(raw, { max, fallback })`: a display name trimmed, cut to `max`, `fallback` when nothing is left; fidice's `NAME_RULE` (16/'Player') is the first consumer (docs/design/dry-round-2.md H4)                                                                                                                                                                                                                                                                                                                                                                                                         |
| `events.ts`         | The event stream sound and history read alike (docs/design/briscola-sound-history.md §3.5): `GameEvent<K, D>` (`id` the event's index), `EventCopy<E, C>` (summary line, detail rows), `EventSound<E, R>` (event -> `Phrase` or null), `lastEventId`, `newEvents(prev, next)` (the ids beyond `prev`; none on a first paint or a re-sent frame)                                                                                                                                                                                                                                                                  |
| `recentGames.ts`    | The record every finished game leaves in browser storage (the owner, 2026-09-25): `RecentGame` (`at`, `mode`, `players`, `score`, `winner`, `outcome`), `Outcome`/`OUTCOMES`, `RECENT_GAMES_CAP` (20), `appendCapped(list, entry, cap?)` (newest first, the oldest dropped), `outcomeFor(userSeat, winner)` (win, loss, or a draw for no winner), `decodeRecentGame` and the lenient `decodeRecentGames` (not a list, or a bad entry, reads as none). The shell reducer builds the record from a game's `cfg.result` adapters; `web/shared/edge/prefs.ts` `recentGamesPref` stores it under `<game>_recentGames` |
| `sound/cues.ts`     | `SOUND_CUES` / `SoundCue`: the twenty generic cues every game maps its own events onto (docs/design/sound-fonts.md §2); `CueSpec`, one row of a game's table (cue + buzz), and `SHELL_CUES`, the tap/yourTurn/win/lose rows every table spreads (§5); the qualified ids (§2.1): `CueId` (`good.trick.steal`, the segments the game's words), `VoiceId`, `Buzz`, `baseOf`, `ladder`, `isSoundCue`, `isCueId`, `decodeCueId`                                                                                                                                                                                       |
| `sound/sound.ts`    | `Sound` (`synth` notes on a voice, `sample` URL, `silence`), `Note`, `OscillatorType`, and the `note` / `synth` / `sample` constructors; `soundMs` (a synth's length from its notes, null for a sample); `web/shared/edge/fx.ts` re-exports the types                                                                                                                                                                                                                                                                                                                                                            |
| `sound/fonts.ts`    | `SOUND_FONTS`, `SoundFontName`, `SoundFont` (`sounds` with qualified keys, `voices`, `durationsMs`, `credits`, `base`), `DEFAULT_SOUND_FONT`, `SAMPLE_MS_FALLBACK`, `isSoundFont`, `badSoundFontMsg(key, value)`, `fontByName`, `resolveCue` / `resolveSound` / `resolveVoice` (the ladder in the font, then its `base`, then the total `default`; §4)                                                                                                                                                                                                                                                           |
| `sound/phrase.ts`   | Phrases (sound-fonts.md §2.2): `Step`, `Voice`, `Sequence`, `Phrase` (a `CueSpec` row is the one-step phrase, so the games' tables widen with no edit), `spec`, `sequenceOf`, `Slot`, `schedule(font, phrase)` from declared lengths, `phraseMs`, `place(font, phrases, gapMs)`, `joinBuzz`, `PHRASE_GAP_MS`                                                                                                                                                                                                                                                                                                     |
| `sound/fonts/*.ts`  | The fonts as data: `default` (gin's legacy tones under generic names, total), `felt` (soft), `arcade` (square waves); played by `web/shared/edge/sound.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `cards/decks.ts`    | The deck kinds (docs/design/card-packs.md §1): `DECK_KINDS`, `DeckSpec`, `DECKS` (`french52` pinned to gin's `makeDeck`; `italian40` with the briscola ids `A 2 … 7 F C R` over `C D S B`), `cardIds`, `isCardId`, `splitId`, `cardName`                                                                                                                                                                                                                                                                                                                                                                         |
| `cards/suits.ts`    | The four Italian suit symbols as SVG data in the print colours, `placedSymbol`, `suitSymbolId`: the glyph face's sprite, linea's pips and a trump badge draw the same shapes                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `cards/packs.ts`    | `CARD_PACKS`, `CardPack` (`Back`, `Faces`, `Attribution`), `FACE_WIDTH`, `packByName`, `isCardPack`, `packsFor(kind)`, `isCardPackFor`, `CardPackFor<K>`, `DEFAULT_CARD_PACKS`, `defaultPackFor`, `badCardPackMsg(key, kind, value)`; `packs/<name>.ts` the packs as data (gin's four backs, hand-written; `linea`, generated by tools/linea.ts)                                                                                                                                                                                                                                                                 |
| `cards/resolve.ts`  | `FaceSpec`, `PaintedBack`, `resolveFace` (the pack's picture for the card, else the glyph, else null for a stranger), `resolveBack` (`none` takes the fallback's), `resolveAspect`, `attributionLine`                                                                                                                                                                                                                                                                                                                                                                                                            |
| `rng.algorithms.ts` | The shared loop escape hatch (`*.algorithms.ts` lint override): `mulberry32`'s generator, with its reason comment and 100% coverage. A helper that needs a loop lands in a sibling `*.algorithms.ts`.                                                                                                                                                                                                                                                                                                                                                                                                            |
