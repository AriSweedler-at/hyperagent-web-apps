# web/shared/lib

Pure, leaf-level TypeScript both games import (docs/ARCHITECTURE.md "Module boundaries and
contracts"). Compiled by `tsconfig.pure.json` without DOM or node libs; lint runs the full
functional profile here (no loops, `let`, mutation, classes, `throw` or expression statements).

| Module              | Holds                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `result.ts`         | `Result<T, E>` and `ok / err / map / mapErr / andThen / unwrapOr`                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `rng.ts`            | `Rng = () => number`; `mulberry32` re-exported from `rng.algorithms.ts`                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `json.ts`           | Decoder combinators over `unknown` returning `Result<T, DecodeError>`: leaves, `arrayOf`, `pair`, `record`, `object` (optional fields become optional keys), `oneOf`, `taggedUnion` (one case decoder per tag, run over the whole input and returned unchanged), `map`, `refine`                                                                                                                                                                                                                                               |
| `game.ts`           | The two-seat primitives both engines re-export from their `engine/types.ts` (`Seat`, `Pair<T>`, `Player`, `Now`, `RuleError`), the helpers `SEATS` / `otherSeat` / `setAt`, the decoders `seat` / `count` / `timestamp`, and `TwoSeatEngine<S, V, A, Opts>`: the contract each engine's `index.ts` publishes as `ENGINE` (`create`, `apply`, `viewFor`, `legalActions`, `actorOf`, `over`, `decodeState`, `decodeView`, `decodeAction`), which the shared shell's `cfg.engine`, the replay harness and the codecs type against |
| `roomCode.ts`       | Room-code alphabets, lengths, peer-id prefixes, sanitiser/validator per game                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `protocol.ts`       | The two-seat wire protocol (shared-shell design §4.5): `twoSeatProtocol({ decodeAction, decodeView, room })` gives a game its seven frame builders and three decoders with the legacy key order (`welcome`/`lobby` spread the room after `hostName`), plus `isGuestFrame`, `guestNameFor` and the `WIRE_TAGS`/`NAME_MAX`/`TOAST_MAX`/`DEFAULT_GUEST_NAME` literals                                                                                                                                                             |
| `clock.ts`          | `Clock` and `Timer` types; implementations live in `web/shared/edge/clock*`                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `invite.ts`         | The `?join=<code>` invite link every game shares: `JOIN_PARAM`, `inviteUrl`; the readers (`joinCodeFrom`, `withoutJoin`) live in `web/shared/edge/invite.ts`, over the platform's `URLSearchParams`                                                                                                                                                                                                                                                                                                                            |
| `sound/cues.ts`     | `SOUND_CUES` / `SoundCue`: the twenty generic cues every game maps its own events onto (docs/design/sound-fonts.md §2); `CueSpec`, one row of a game's table (cue + buzz), and `SHELL_CUES`, the tap/yourTurn/win/lose rows every table spreads (§5)                                                                                                                                                                                                                                                                           |
| `sound/sound.ts`    | `Sound` (`synth` notes on a voice, `sample` URL, `silence`), `Note`, `OscillatorType`, and the `note` / `synth` / `sample` constructors; `web/shared/edge/fx.ts` re-exports the types                                                                                                                                                                                                                                                                                                                                          |
| `sound/fonts.ts`    | `SOUND_FONTS`, `SoundFontName`, `SoundFont`, `DEFAULT_SOUND_FONT`, `isSoundFont`, `badSoundFontMsg(key, value)`, `fontByName`, `resolveSound` (a partial font falls back to the total `default`)                                                                                                                                                                                                                                                                                                                               |
| `sound/fonts/*.ts`  | The fonts as data: `default` (gin's legacy tones under generic names, total), `felt` (soft), `arcade` (square waves); played by `web/shared/edge/sound.ts`                                                                                                                                                                                                                                                                                                                                                                     |
| `rng.algorithms.ts` | The shared loop escape hatch (`*.algorithms.ts` lint override): `mulberry32`'s generator, with its reason comment and 100% coverage. A helper that needs a loop lands in a sibling `*.algorithms.ts`.                                                                                                                                                                                                                                                                                                                          |
